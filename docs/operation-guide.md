# 操作手順書

## ログイン

ログイン画面でメールアドレスとパスワードを入力する。デモでは管理者、担当者、閲覧者の役割ボタンを選ぶと、公開デモ用ログイン情報が自動入力される。手入力でのログインもできる。

ログイン失敗時は「メールアドレスまたはパスワードが正しくありません。」と表示する。

## 一覧

`/jobs` で案件一覧を確認する。全案件数、期限超過、7日以内、未完了の集計を表示し、期限状態は色と文字で示す。

adminとviewerは全案件を閲覧できる。staffは自分が担当する案件だけを閲覧できる。

## 検索

キーワード、担当者、進捗、期限、請求状況で絞り込む。条件はURLクエリに反映される。

## 詳細

`/jobs/[id]` で案件情報と更新履歴を確認する。閲覧権限がない案件は「案件が見つからないか、閲覧権限がありません。」と表示する。

## 登録

adminとstaffが `/jobs/new` から登録できる。staffは自分を担当者として登録する。viewerは登録できない。

## 編集

adminは全案件、staffは自分の担当案件のみ編集できる。viewerには編集ボタンを表示しない。権限外の編集URLへ直接アクセスした場合も拒否する。

## CSV移行

adminだけが `/csv-import` を利用できる。

1. CSVファイルを選択する
2. プレビューと検証結果を確認する
3. 正常行だけを取込確認へ進める
4. 取込を実行する
5. 成功行数、失敗行数、エラー件数を確認する

staffとviewerがCSV移行へ直接アクセスした場合は、案件一覧へ戻して権限エラーを表示する。

## CSV出力

案件一覧のCSV出力から、現在の絞り込み条件を反映したCSVをダウンロードする。出力時はCSVインジェクション対策を行う。

## 利用者・権限管理

adminだけが `/users` を利用できる。利用者の権限と有効状態を更新できる。最後のadmin喪失防止と保存成功・失敗メッセージは初回版の既知制約としている。

## レスポンシブ

PC、タブレット、スマートフォン幅で主要画面の表示、横はみ出し、主要操作をPlaywrightで確認している。
