# 現行業務フロー

1. 事務担当者が点検依頼を受ける。
2. ExcelまたはGoogleスプレッドシートへ案件番号、顧客名、現場名、住所、点検種別を入力する。
3. 担当者と点検予定日を入力する。
4. 報告書提出期限を手作業で入力する。
5. 現場担当者が進捗や備考を更新する。
6. 事務担当者が報告書提出と請求状況を更新する。
7. 期限超過や未請求をフィルタで確認する。
8. 月次で完了・未完了を手作業で確認する。

## 現行運用の弱点

- 同時編集で誤入力が起きる
- 案件番号の重複を防げない
- 期限や金額のチェックが人に依存する
- 更新者と変更内容が追えない
- 列の意味や入力ルールが担当者の記憶に依存する
